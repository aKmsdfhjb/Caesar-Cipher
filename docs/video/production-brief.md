# Caesar Cipher — Video Production Brief

**Target:** 35 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

A crisp browser capture demonstrating message input, shift selection, encryption and decryption. Use only harmless sample text. Explain that this is a historical substitution cipher, not secure encryption.

## Shot list

0–5s: title card. 5–13s: enter a short sample message and shift. 13–22s: reveal encrypted text and reverse it. 22–29s: animate alphabet wraparound. 29–35s: show Python function, browser demo and educational security note.

## Voiceover draft

A minimal interactive coding demo explaining Caesar shifts through real browser footage, clean typography and a simple alphabet transformation graphic.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify any prediction, API response or feature shown in the edit.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.

## Generation prompt

Create a 35 seconds 16:9 1080p editorial software-project showcase for “Caesar Cipher”. Follow a warm ivory, black serif and vermilion monospaced Swiss portfolio aesthetic with precise grid alignment, thin rules, subtle transitions and clean screen-recording inserts. Use authentic project screenshots and the shot list above. Keep typography crisp and restrained. Do not fabricate UI, model outputs, performance metrics, users, testimonials or product capabilities. Avoid generic AI robots and neon sci-fi visuals. Finish on a quiet title card with the project name and GitHub repository.
