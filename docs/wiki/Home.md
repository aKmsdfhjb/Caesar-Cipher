# Caesar Cipher — Project Wiki

A small Python implementation and browser-based demonstration of Caesar-shift encryption and decryption. It is an educational substitution cipher, not secure encryption.

## Quick start

```bash
python Caesar_Cipher.py
```
Open `index.html` in a browser for the client-side interface.
